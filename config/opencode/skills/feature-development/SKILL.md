# Feature development

1. Restate the feature in one sentence and list out-of-scope items.
2. Locate the nearest existing pattern (similar route, component, or service).
3. Implement the smallest vertical slice that matches that pattern.
4. Add or update tests only where the repo already tests this layer.
5. Summarize: files touched, how to run, and residual risks.
